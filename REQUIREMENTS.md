# Requirement list for future features

## Overview

This document holds a requirement list for future developers for continued work 

## Possible features

| No. | Priority | Description | Status |
|-----|----------|-------------|--------|
| 1 | A | WebSequenceDiagram.com integration | Not started |
| 2 | A | Support for Icelandic into the LLM | Not started |
| 3 | A | Git diff (working tree) feature so that the user can compare their code to the chatbot's  | Not started |
| 4 | A | A better chatbot under the hood | Not started |
| 5 | A | The user can export a conversation as a PDF or Markdown file for offline reference. | Not started |
| 6 | A | The user can upload files or photos for more difficult tasks | Not started |
| 7 | A | The chatbot can accept a pasted error message and explain what went wrong and how to fix it. | Not started |
| 8 | A | The user can enter a "quiz mode" where the chatbot tests their understanding of a concept they previously worked through. | Not started |
| 9 | A | The user can bookmark individual code blocks or steps to a personal saved snippets panel. | Not started |
| 10 | A | The chatbot provides a short summary of concepts covered at the end of a conversation session. | Not started |
| 11 | B | The user can configure the maximum number of steps shown per response (overriding the default of 5). | Not started |
| 12 | B | The user can choose a preferred programming language that the chatbot defaults to when generating code. | Not started |
| 13 | B | The chatbot supports voice input so users who struggle with typing can describe their problem verbally. | Not started |
| 14 | B | The user can view a glossary of programming terms introduced during a session, with plain-language definitions. | Not started |
